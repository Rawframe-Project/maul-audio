# Public functions that do not enter the library's floating-point
# environment (tools/check_float_env.py), under the reason they need not.
# Every other public function enters it: the Spatial simulation's calls,
# whose bakes, paths and estimates are promised the same bits whatever
# the host's flush-to-zero, denormals-are-zero or rounding mode
# (docs/internals/realtime.md).
